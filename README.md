
DataNurse is a personal health monitoring app. Rather than shipping a fixed set of measurements, it lets you define your own reading types — name the fields, pick their units, set a target and an averaging window — and it builds the form, stat cards and charts for each one. Blood pressure and glucose come as editable starting points, and any type can be charted against another to spot correlations. Alongside readings, it tracks medications: record the dose and schedule, then tick off each day's doses and watch your adherence build up. Built with React and Vite on Firebase Realtime Database, with Google sign-in.
